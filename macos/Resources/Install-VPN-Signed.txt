VayuSetu VPN for macOS 1.0

Check the release notes for this disk image's signing and notarization status. Do not disable Gatekeeper globally.

Drag VayuSetu.app to Applications before using the system extension. macOS may require approval for the extension in System Settings. Import your WireGuard configuration, save a DNS-over-HTTPS resolver, then connect and verify the handshake, external IP and DNS behavior.

Signing and OS connection status do not establish leak-free protection. DNS -> VPN is unavailable. Live DNS-path/filter, IPv6, leak and recovery validation remain outstanding.

Preview and VPN app data are separate. Existing preview credentials and iPhone profiles are not transferred automatically.
