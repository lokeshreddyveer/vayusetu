# ADR-002: Provider-independent profiles

Status: Proposed. Date: 2026-10-10.

## Decision

Represent provider identity as optional metadata, and protocol as an explicit capability. WireGuard is the initial implementation; Surfshark is not a required provider. Store resolver profiles independently of VPN profiles.

## Acceptance evidence

Contract tests must accept valid generic WireGuard profiles and reject unsupported protocol combinations without implying equivalent capabilities.
