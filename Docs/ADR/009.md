# ADR-009: Diagnostic methodology and evidence

Status: Proposed. Date: 2026-10-10.

## Decision

Keep independent evidence per check with timestamp, method, scope and verdict. Unverified, unsupported, inconclusive and failed are distinct. Public IP and adapter counters are observations, not comprehensive leak proof.

## Acceptance evidence

Use controlled destinations and packet captures, positive and negative controls, resolver/filter tests and failure injection. Record external endpoints and user consent for optional probes.
