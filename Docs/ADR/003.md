# ADR-003: WireGuard dependency ownership

Status: Proposed. Date: 2026-10-10.

## Decision

Reuse the pinned official WireGuard integration and documented patches. Keep compiler, dependency versions, licenses and patch provenance reproducible. Do not claim that a dependency scan audits OS network behavior.

## Acceptance evidence

Rebuild native archives on each supported platform; inspect executable symbols and licenses; scan release dependencies and verify patch behavior.
