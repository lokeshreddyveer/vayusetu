# ADR-010: Shared platform boundaries

Status: Proposed. Date: 2026-10-10.

## Decision

Share domain models, validation, policy compilation, storage contracts and diagnostic verdicts. Keep provisioning, Keychain access-group details, Network Extension adapters and UI in platform targets. Introduce packages incrementally; preserve ios/ and macos/ locations requested by the user.

## Acceptance evidence

Compile and test shared packages on both platforms and verify capability differences explicitly. The user selected iOS first on 2026-10-10. Continue the existing iOS targets; defer macOS targets.

## Implemented foundation (iOS 0.4.0)

Packages/VayuSetuCore is a real local Swift package linked by both iOS app targets. It owns configuration metadata, lifecycle stages, evidence verdicts, retry policy and session-history contracts. Platform Keychain, Network Extension and UI remain in ios/. Shared networking parser/transport/policy extraction is not finished; this is an incremental module boundary, not completion of all proposed packages.

The UI follows one VayuSetu design: dark glass, blue accents, a circular power control, native tabs and secondary Logs/History screens. No new image assets were generated.
