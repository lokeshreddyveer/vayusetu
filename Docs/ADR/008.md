# ADR-008: Authoritative connection lifecycle

Status: Proposed. Date: 2026-10-10.

## Decision

Use a single connection controller. Distinguish tunnel establishment from IPv4, IPv6, DNS and routing verification. Model degraded, blocked, suspended and failed outcomes separately. Use operation identities, cancellable deadlines and bounded retry with backoff.

## Acceptance evidence

State-transition contract tests must cover late callbacks, cancellation, duplicate requests, network changes and rollback failures. No OS connected callback alone may mark security verified.
