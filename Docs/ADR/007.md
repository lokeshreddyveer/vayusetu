# ADR-007: Secrets and extension IPC

Status: Proposed. Date: 2026-10-10.

## Decision

Retain Keychain storage and persistent-reference IPC. Ordinary metadata and diagnostics must never contain private keys, preshared keys or authentication secrets. Prefer redacted exports and bounded structured IPC.

## Acceptance evidence

Test actual app/extension access groups on provisioned devices, hostile import size/content, redaction and deletion rollback. Never capture raw backend runtime configuration in exported logs.
