# ADR-004: DNS transport and direct-DNS feasibility

Status: Feasibility gate open. Date: 2026-10-10.

## Decision

Evaluate native DoH settings first. Default to VPN → DNS. DNS → VPN is advanced and unavailable in the target policy compiler unless DNS-only bypass is proven. Existing IP excluded routes allow arbitrary traffic to resolver IPs and cannot establish this guarantee. Do not weaken the requirement silently or claim that DNS relays website traffic.

## Acceptance evidence

On provisioned hardware capture IPv4/IPv6 paths for DNS and arbitrary HTTPS to the same resolver addresses. Test bootstrap, address changes and reconnects. If native APIs cannot isolate DNS transport, document an unsupported capability or evaluate a narrowly scoped custom DNS design.
