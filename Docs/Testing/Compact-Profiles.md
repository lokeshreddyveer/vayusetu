# Compact profiles and management

Profile list rows and connection card use tighter vertical spacing. Details preserve complete configuration values and use compact rows; edit forms group Interface, Peer and Advanced settings. Scroll indicators are hidden; interactive controls retain at least 44-point targets. Imports from files are bounded and validated, then open an editor before any saving. Cancel leaves storage and the current VPN unchanged.

IKEv2 deletion requires a disconnected VPN and explicit confirmation. Only the exact VayuSetu-owned native system configuration and that profile’s credential accounts are removed. Runtime storage failures attempt credential/metadata rollback; deletion is not claimed crash-atomic. Profile-specific and global backups exclude credentials by default and use the existing password-encrypted container. Including credentials requires an explicit toggle. Imported native profiles receive new IDs and do not auto-connect.
