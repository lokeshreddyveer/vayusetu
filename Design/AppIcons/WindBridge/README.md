# VayuSetu — Wind + Bridge, revision 2

Two smooth wind strokes join tangentially at the apex of a broad open arch. Rounded terminals, 64px consistent stroke, 60.5% canvas width, centered at (512,512). No text, locks, shields or ornament.

Dark/master: #14171C to #0B0D10 vertical gradient. Mark base #2DB6C9 with a subtle #3EC0D1 upper highlight. Light: #F9FAFB to #EFF2F5 with identical teal geometry. Tinted: pure white on genuine transparency. All masters 1024x1024; no pre-rounded outer corners.

The initial image-generated wave concept was rejected. Final delivered geometry is rendered directly using Core Graphics from editable paths; all variants use identical geometry. SVG and repeatable Swift renderer are included.

Preview files are exactly 180,120,60 and29 pixels square. Legibility-Previews.png displays them at their actual pixel sizes. Canvas dimensions and opacity/transparent corners were verified; small previews were visually inspected. At29px the arch remains readable, while the subtle highlight becomes negligible.

This design package does not rebuild or replace the installed app or signed release artifacts.
